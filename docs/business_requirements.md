# Бизнес-требования к приложению Business Metrics Analyzer

## 1. Назначение
Учебное приложение для расчёта и визуализации ключевых показателей эффективности (KPI) предприятия.

## 2. Целевая аудитория
- Бизнес-аналитики
- Руководители отделов
- Финансовые специалисты

## 3. Функциональные требования
1. Ввод исходных данных о выручке и затратах по месяцам.
2. Расчёт средней выручки за период.
3. Расчёт рентабельности (в процентах).
4. Визуализация динамики показателей (в разработке).

## 4. Нефункциональные требования
- Язык реализации: Python 3.10+.
- Библиотеки: pandas, matplotlib.
- Кроссплатформенность (Windows, macOS, Linux).
- Простой запуск: `python main.py`.

## 5. Ограничения
- Учебный проект, не предназначен для production-использования.
- Данные вводятся локально, без подключения к БД.
